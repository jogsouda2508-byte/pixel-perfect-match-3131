EDIRAA - PROFILE LINKS + MORE-PAGE FEATURES
============================================

HOW TO APPLY
1. Unzip this folder.
2. Copy everything inside it (src/ and supabase/) into your project root and choose "Replace".
   You can delete this CHANGES.txt afterwards - it is not part of the app.
3. Supabase -> SQL Editor -> paste supabase/migrations/20261013000000_saved_groups.sql -> Run.
   (Needed for Saved Posts and Groups. Safe to run more than once.)
4. npm run dev   (no new packages are needed)
   The dev server regenerates src/routeTree.gen.ts by itself; the copy in this zip is
   already up to date.

These files are based on the main branch of your GitHub repo (latest commit "Removed mock data").
If you changed any of the REPLACED files locally after that, merge by hand instead of overwriting.
