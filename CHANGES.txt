EDIRAA - PROFILE LINKS + LOCATION + TAG PEOPLE
==============================================
HOW TO APPLY
1. Unzip, copy src/ and supabase/ into your project root, choose "Replace". (CHANGES.txt is not part of the app.)
2. Supabase -> SQL Editor -> run supabase/migrations/20261019000000_post_location_tags.sql
   (needs the earlier migrations already run; safe to run more than once).
3. npm run dev   (no new packages, no API keys needed)

WHAT'S IN IT
- Profile links: avatars/names open /u/<username> (stories, notifications, post cards, people rows);
  profile page has a working "Tagged" tab.
- Location: searchable picker (Photon / OpenStreetMap, no key), dialog on desktop, bottom sheet on mobile;
  debounced, cancels stale requests, handles empty/error/rate-limit; "Use my current location" is optional.
  Saved with the post: place id, name, address, city (never coordinates).
- Tag People: searches real accounts (get_people), multi-select, Cancel/Done, max 20, load more.
  Tags are written only by the database function set_post_tags, which checks you own the post and that each
  person can see it (Friends / Local Community rules). Tagged people get a "tagged you" notification.
- Post display: location + "with @a and N others" on feed posts and videos.
- New in this round: if the database skips someone (e.g. non-friend on a Friends post) you now get a
  "couldn't tag everyone" notice instead of a silent success. Added src/test/post-extras.test.ts.

- Round 2 (UI): Create Post page and the photo/video "Details" step now share ONE block:
  row 1 = Location | Tag People, row 2 = Add Hashtag. Chosen items turn violet and show the place / avatars
  with an X to remove; tap to edit. Hashtags typed in the caption appear as chips. "Add Hashtag" inserts # and
  focuses the caption in both places. Fixed: hashtags in Indian scripts were cut after the first letter.
  If you still see "Location tagging is coming soon", the new files have not been copied in / dev server not restarted.
