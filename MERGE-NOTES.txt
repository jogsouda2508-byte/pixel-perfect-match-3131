1. Copy src/ and supabase/ from this package into the project root, choose "Replace".
2. DELETE these two files (they belong to the old story-like design that the zip replaces;
   leaving them makes `npm test` / tsc fail):
     src/lib/story-like.ts
     src/test/story-like.test.ts
3. Supabase -> SQL Editor: run supabase/migrations/20261025000000_notifications_merge.sql
   (AFTER all your other migrations; safe to run twice). See "SQL" below for why.
4. npm run lint && npm test && npm run build
