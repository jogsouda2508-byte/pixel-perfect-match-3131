SabZone animated splash - HOW TO APPLY
1. Unzip and copy everything into your project root (choose Replace). Paths match the project.
2. Then rebuild the Android web bundle:
     npm run build
     (copy the build output to android-web/ the same way you did before)
     npx cap sync android
3. Rebuild the app in Android Studio and run.
